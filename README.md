# تقارير الفلك — صفحة الموبايل

صفحة واحدة تفتحها من الموبايل أو الكمبيوتر. ترفع عليها شيت Loopers، فتعمل ملف PDF واحد فيه:
خطاب الفلك على الورق الرسمي، ثم قائمة الوحدات، ثم كل التقارير بنفس الترتيب، مع فهرس (Bookmarks) لكل مصعد.

لا تحتاج تسطيب أي حاجة. الشيت والتقارير تُعالج داخل الموبايل نفسه، ولا تُرفع على أي سيرفر.

## الرفع على GitHub Pages (مرة واحدة)
1. اعمل Repository جديد على GitHub (مثلاً `falak-reports`).
2. ارفع الملف `index.html` فيه (Add file ← Upload files).
3. من Settings ← Pages: اختار Branch = `main` وفولدر `/ (root)` ثم Save.
4. بعد دقيقة أو اثنين يكون الرابط: https://abomosa960-web.github.io/elevator-Report/
5. افتح الرابط من الموبايل، ومن قائمة المتصفح اختار «إضافة إلى الشاشة الرئيسية» عشان يبقى زي التطبيق.

## الاستخدام
1. **اختر شيت الإكسل** (تصدير Loopers).
2. **الفترة:** البرنامج يختار الشهر الحالي تلقائياً. ممكن تختار شهر تاني، أو سنة كاملة، أو تغيّر «من» و«إلى» لأي مدة.
3. **راجع اسم العميل** وأنواع التقارير: كل الأنواع الموجودة في الشيت تظهر ومعلّمة كلها. استخدم «الشهرية فقط» أو «الإصلاح فقط» أو اختار الأنواع بنفسك.
4. **المصاعد في هذه الفترة:** هنا تشوف كل مصعد في الشيت؛ لو مصعد ليس له تقرير يظهر بالبرتقالي مع تاريخ آخر تقرير له.
5. **قائمة التقارير:** عدّل اسم الوحدة أو التاريخ، ألغِ علامة تقرير، رتّب بالأسهم، أو أضف تقرير PDF من عندك.
6. **نص الخطاب:** يتكتب تلقائياً حسب الفترة وعدد المصاعد والأنواع؛ تقدر تعدّله، و«إرجاع النص التلقائي» يرجّعه.
7. اضغط **إنشاء ملف PDF** ثم **تنزيل** أو **مشاركة** (واتساب / إيميل).

## لو التقارير لم تنزل (رسالة «المتصفح منع التنزيل المباشر»)
ده معناه أن موقع Loopers لا يسمح للصفحة بتنزيل التقارير مباشرة. الحل مرة واحدة فقط:
1. افتح https://script.google.com ← New project.
2. امسح الموجود والصق محتوى الملف `Code.gs`، واحفظ.
3. Deploy ← New deployment ← النوع **Web app**:
   - Execute as: **Me**
   - Who has access: **Anyone**
4. Deploy، وافق على الصلاحيات، وانسخ رابط الـ Web app (ينتهي بـ `/exec`).
5. في الصفحة: **الإعدادات** ← الصق الرابط ← **حفظ** ← **تجربة التنزيل**.

الإعداد ده يتحفظ على كل جهاز لوحده، فلو حد تاني من الفريق هيستخدم الصفحة يحط نفس الرابط مرة واحدة عنده.
